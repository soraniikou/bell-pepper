🌸 bell-pepper
石ころから芽が出て、花びらに願いを書いて、小鳥が願いを届けてくれる――
そんな小さな思いを大切にできるアプリです。
🐦 アプリについて
bell-pepper は、ウィンドベル🔔の音と共に気持ちを軽くするための応援Webアプリです。
🪨 石ころから芽が出る
🌸 芽が花びらになる
💮 花びらに願いを書く
🐦 小鳥が願いを届けてくれる
個人情報の取り扱いについて
このアプリ「ベルペッパー」は、あなたが書いた願いのテキストをどこにも保存せず、どこにも送信しません。
入力した文章はこの画面上でのみ表示され、サーバーやデータベースには一切送信されません
スマートフォンやパソコンにもデータとして保存されません(ページを閉じる・更新すると内容は消えます)
運営者を含め、誰もあなたが書いた内容を見ることはできません
アクセス解析や広告のための個人情報の収集も行っていません
一度きり、その瞬間だけのための場所です。安心して、思うままに書いてください。
